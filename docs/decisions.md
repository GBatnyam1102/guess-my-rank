# Үе 0 — Шийдвэрүүд (v1.4-д санал болгох)

Төлөвлөгөөний "Шаардлагад дутуу зүйлс" хүснэгтийн 11 асуултыг санал болгосон утгаар нь хэрэгжүүлсэн.
Утгууд нэг дор байгаа тул өөрчлөх хялбар: `shared/src/constants.ts`.

| #  | Асуудал | Хэрэгжүүлсэн шийдвэр | Хаана |
| -- | ------- | -------------------- | ----- |
| 1  | Холбогдсон ч таахгүй суусан Guesser | Guessing-д 120 сек; дуусахад SKIPPED, 0 оноо | `DEFAULT_TIMINGS.guessingMs` |
| 2  | Ranker тасрах / удаан эрэмбэлэх | 60 сек reconnect; эс бөгөөс round SKIPPED → дараагийн Ranker. Ranker-ийн хугацаа Random 3 мин, Custom 5 мин | `disconnectGraceMs`, `rankingRandomMs`, `rankingCustomMs` |
| 3  | Host гарах / тасрах | Гарвал шууд, 60 сек тасарвал дараагийн онлайн тоглогчид (нэгдсэн дарааллаар) шилжинэ | `hostGraceMs`, `engine.ts → transferHost` |
| 4  | Тоглогч 2-оос доош | Тоглоом дуусч Final Leaderboard (`NOT_ENOUGH_PLAYERS`) | `engine.ts → step` |
| 5  | Эхэлсний дараа шинэ тоглогч | Зөвхөн Lobby-д нэгдэнэ; дараа нь зөвхөн session token-оор дахин нэгдэнэ | `engine.ts → join` |
| 6  | "Хүн бүр нэг удаа" горимд гарах | Гарсан хүний ээлж алгасагдаж, round-ын тоо багасна | `plannedRounds()` |
| 7  | Upload-ын хязгаар | JPG/PNG/WebP/HEIC, файл бүр ≤ 10 MB, яг тохируулсан тоо | `UPLOAD_*`, `server/src/images.ts` |
| 8  | Custom зураг хадгалах хугацаа | Тоглоом дууссанаас 24 цагийн дараа устгана (sweep 10 мин тутам) | `CUSTOM_IMAGE_RETENTION_MS`, `RoomManager.sweep` |
| 9  | Refresh бүгдийг үү, нэгийг үү | Бүх зургийг солино; аль болох өмнө гараагүй зургаас | `engine.ts → refresh, drawItems` |
| 10 | Зохисгүй агуулга | Хувийн өрөө (код/линк), EXIF арилгана. **"Report" товч хараахан хийгдээгүй** | `images.ts` |
| 11 | Цөөн round-д зарим нь Ranker болохгүй | "Хүн бүр нэг удаа" анхны утга | `DEFAULT_SETTINGS` |

Нэмэлт шийдвэрүүд:

- Pass & Play байхгүй (Q-06): тоглогч бүр өөрийн төхөөрөмжөөс орно.
- Ranker-ийн эрэмбэ: 1 = хамгийн дуртай. Guesser мөн адил.
- Guesser бүрт тусдаа хольсон дараалал өгнө, тэр нь Ranker-ийн хариутай хэзээ ч ижил биш (FR-66).
- Ranker-ийн түгжихээс өмнөх ажлын дараалал зөвхөн тухайн хөтчид (sessionStorage) хадгалагдана; сервер зөвхөн түгжсэн дарааллыг авна.
- Тоглогчийн холболт тасрахад 60 сек-ийн хугацаа нь socket тасарснаас эхэлнэ. Сервер ping-ээ 10 сек тутамд илгээдэг (8 сек хүлээнэ), тиймээс утас гэнэт унтарвал ~18 сек-д илэрнэ.
- Сервер дахин асахад бүх тоглогч OFFLINE болж, 60 сек-ийн хугацаа тэр мөчөөс эхэлнэ (NFR-08).

Bot-той өрөө (2026-11-07 нэмсэн):

- Өрөө хоёр төрөлтэй: `HUMANS` (найзууд кодоор нэгдэнэ) ба `BOTS` (нэг хүн + сервер дээр ажиллах bot-ууд). Хоёрыг холихгүй: bot-той өрөөнд код/линкээр хэн ч нэгдэхгүй (`BOT_ROOM`), найзуудын өрөөнд bot нэмэхгүй (`NOT_A_BOT_ROOM`).
- Bot-ын нүүдлийг `shared/src/bots.ts → botMoves` (цэвэр функц) шийднэ; сервер 1.5–8 сек "бодоод" (`BOT_THINK_MS`) тушаалыг энгийн тоглогчийнх шиг engine-ээр дамжуулна. Тиймээс bot ч бүх дүрэм, таймерт захирагдана.
- Bot санамсаргүй эрэмбэлж, санамсаргүй таана. Custom горимд Ranker болбол сангийн зургаас авна.
- Bot үргэлж онлайн, Host болохгүй. Сүүлийн хүн гарвал тоглоом дуусч, өрөө устна. Сервер дахин асахад bot-ууд шууд үргэлжилнэ.
- Bot-той өрөөнд тоглогчийн дээд тоо 10 хэвээр; Host Lobby-д bot нэмж, хасна.

## Deploy (2026-11-07)

Шаардлага: бүх зүйл үнэгүй, сервер 24/7 асаалттай, яг 1 instance. Төлөвлөгөөний Vercel + Fly.io + Neon + R2-оос дараах байдлаар өөрчилсөн ([заавар](deploy.md)):

| Давхарга | Төлөвлөгөөнд | Хэрэгжүүлсэн | Шалтгаан |
| -------- | ------------ | ------------ | -------- |
| Тоглоомын сервер | Fly.io эсвэл Railway | Oracle Cloud Always Free VM (Tokyo), Docker | Fly.io, Railway-д үнэгүй түвшин байхгүй. Oracle VM үргэлж асаалттай, Монголд ойр |
| Frontend | Vercel | Мөн тэр VM дээр Next.js standalone | Нэг deploy команд, нэг бүртгэл. Vercel-д шилжүүлэхэд `NEXT_PUBLIC_SERVER_URL` л тохируулна |
| Өгөгдлийн сан | Neon эсвэл Supabase | VM дээрх Postgres 17 (Docker volume) | Neon-ий үнэгүй түвшин сард 100 CU-цаг. 24/7 холболттой сервер ~180 цаг хэрэглэнэ. Өрөөний өгөгдөл түр, контент `categories.json`-оос импортлогдоно |
| Зураг | Cloudflare R2 | `local` driver, Docker volume | R2-д карт холбох шаардлагатай, driver хараахан туршигдаагүй. Хожим `STORAGE_DRIVER=r2` болгоход хангалттай |
| HTTPS | — | Caddy (Let's Encrypt), Cloudflare DNS "DNS only" | Гэрчилгээг автоматаар авч, сунгана |
